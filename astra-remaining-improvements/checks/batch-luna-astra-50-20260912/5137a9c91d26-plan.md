## Main defects and repair

`savePage` authorizes against input.spaceSlug, then fetches input.pageId globally and uses the authorized space context even if the page belongs to another space. It also silently creates a new page when a supplied page ID is missing. Reject missing explicit IDs and page/space mismatches before any write; derive edit authority from the actual page relation as well as requested space. Preserve existing admin/contributor/archive policies and parse inputs inside the service so direct callers cannot bypass action validation.

Page/revision/activity are in one transaction, but syncTags runs afterward through global Prisma and deletes/recreates links separately. Move tag lookup/upsert/link replacement into the same transaction client and keep all entity/revision/activity/tag changes together. Inspect schema uniqueness and avoid races in tag creation. Slug and version lookups are currently outside the transaction; at minimum scope them correctly and document remaining concurrent revision/slug conflict behavior, or add a real optimistic version contract across form/action/service with tests if feasible. Do not call an untested mock a durable transaction proof.

Read projections also need the existing canReadPage policy: listAccessibleSpaces includes every page, featured pages have no published filter for viewers, and activity includes related page content based only on space access. Apply viewer-visible page predicates before limits/counts and sanitize nested space.pages in getSpaceOverview so a filtered top-level pages list does not coexist with hidden raw pages. Preserve contributor/admin broader reads. Search already post-filters canReadPage but applies limit first; correct that ordering or specify a query predicate that enforces policy before taking results.
