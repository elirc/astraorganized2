# J2 library tracker review

Read all five original Java source files and inspected original onboarding material. No applicable AGENTS.md exists in the project ancestry. The original storage wrote books and borrowers separately, accepted missing/defaulted fields and permissive booleans, exposed mutable entities, lacked book/borrower edit/delete and archive workflows, reused IDs after deletion, and erased loan details on return. EOF and malformed data were not handled consistently.

Implemented immutable versioned entities, full book/borrower CRUD, explicit archive/restore and deletion guards, current loans plus retained accepted-title/name history, validation of dates, normalized unique nonempty borrower emails, complete aggregate reference checks, durable allocation watermarks, strict legacy-pair import into a separate snapshot without changing either legacy file, and cooperative lock/baseline/atomic save-before-memory commits. The CLI remains a foundation project; HTTP/auth/SQL extensions will be explained explicitly in the course.
