# Feedback board implementation review

Reviewed all 26 original source files, including the JSON repository, service mutations, authentication, forms, and staff pages. Existing explanatory material is preserved. The original collection data file will remain unchanged.

Main defects: unsigned user-ID cookie; non-atomic multi-write operations; no durable concurrency boundary; missing service visibility checks; leaked moderation details; no post/comment edit/delete workflow; duplicate vote/follow race; merges without target/version/privacy checks; ineffective settings; throwing form errors that discard drafts.

Implementation direction: retain Next/React routes and visual identity; explicit non-overwriting local setup with generated credentials; SQLite transaction around a validated small JSON aggregate; server-owned identity and role refresh inside mutations; strict commands, record versions, atomic audit and notifications; controlled client forms with drafts and conflict recovery; meaningful persistence and browser tests. The single-aggregate storage tradeoff is explained and relational migration is a later exercise.
