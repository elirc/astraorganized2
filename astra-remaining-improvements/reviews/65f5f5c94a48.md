# Ecommerce source review

Canonical grokbuildecommerceproject; 33 staged files, 25 audited source files. No project AGENTS.md. Product and order reads are unprotected and unbounded. Product creates pass arbitrary request bodies through to Prisma. Checkout trusts a supplied user ID, accepts unvalidated items and persists zero prices/total without stock reservation or a transaction. Registration/login have a fallback secret and seven-day tokens. No migrations, seed, backend test runner or TypeScript configs. Frontend feature imports point at nonexistent API paths, Add to Cart is a placeholder and order errors can look like an empty history.

Implement authenticated customer/admin scope, complete product CRUD and archive, cart editing, atomic checkout with current Decimal prices and immutable line snapshots, stock-safe cancellation and an explicit simulated fulfillment workflow. A durable per-customer checkout key and normalized payload fingerprint should make an ambiguous retry safe. No live payments, external accounts or personal databases will be used. Add real PostgreSQL/concurrency/browser evidence and detailed project-specific learning documents.
