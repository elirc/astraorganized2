- [review #1 / backlog P4 "buildjira"] Removed the `ApplyPatch` ↔ `CopyMutableIssueFields` coupling. `BuildJiraStore.UpdateIssue` now publishes the validated candidate by replacing the stored object (`candidate.UpdatedAt = ...; var index = state.Issues.FindIndex(i => i.Id == issueId); state.Issues[index] = candidate; issue = candidate;`) and `CopyMutableIssueFields` was deleted.
