## Done
- [review #1] `app.js:58-83` — added `normalizeAmounts`, called from `loadTransactions`. Records written by the old build were not bounded to two decimals, so `renderTransactions`' `Math.round(amount * 100)` rounded them for the ledger while `formatCurrency(amount)` rounded them independently for the row — two roundings of the same stored value, which can disagree after an edit. Every stored `amount` is now snapped to `Math.round(x * 100) / 100` as the data enters the program. Deliberately **does not write**: a read that can fail a write is a bad trade, and the normalized value reaches storage on the next successful `commitTransactions`. The comment in the code says so.
