## What Astra did well

The test `"compensates the rollout when audit persistence fails"` proves the restore.

## One-paragraph summary for the index
A good subject — how to version a public API without breaking clients — with a genuinely sharp bug at its centre: the old v1/v2 adapters typed their `version` parameter as a known union and then fell through to the v2 branch for *any* value that was not `"v1"`, so an unsupported version silently got v2 semantics. Astra fixed that with runtime assertions and payload type guards, added ownership and rollout validation before writes, and along the way repaired three source files whose header comments contained `**/route.ts` and were terminating their own block comment. The teaching is thinner than the engineering: no code blocks anywhere, every file is two documents stitched together with two H1s, and VERIFICATION.md cites a superseded test record and reports 10 tests where the log says 11 and the final run says 12. Worth reading for the omission-vs-`false` and unknown-version lessons; verify the test count yourself.
